# Quick Start

Welcome to CCBus! CCBus is an online blockchain toolkit designed to meet the needs of cryptocurrency and DeFi users.

## Overview

CCBus provides a visual interface that allows users to quickly create, deploy, and manage their own cryptocurrencies without writing code. Additional features include cross-chain swaps, batch transfers, batch wallet generation, market cap management, and more.

## Why CCBus?

### 1. Multi-Chain Support

CCBus supports multiple blockchains including Ethereum, BSC, Solana, TON, Sui, Tron, and more — create digital assets across different chains.

### 2. Diverse Mechanisms

Multiple token creation modes: standard tokens, LP reflection, LP mining, hold dividends, and more.

### 3. Smart Contracts

All features are implemented through smart contracts — transparent, fair, and traceable.

### 4. Secure & Stable

Strict review procedures prevent dangerous and fraudulent activities, providing a safe environment.

### 5. Low Cost

Lower token creation and airdrop fees compared to other platforms.

### 6. User Friendly

Visual interface that requires no coding — easy for beginners and experts alike.
