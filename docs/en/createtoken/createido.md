# IDO Presale Creation Tutorial

## 1. What Is an IDO?

IDO (Initial DEX Offering) is a method of issuing tokens on a decentralized exchange. The project team sells tokens at a lower price before listing to raise funds for the liquidity pool and marketing.

### Difference Between IDO and Mint

| Feature | IDO | Mint |
|---------|-----|------|
| **Participation** | Through the official website | Through wallet transfer |
| **Referral Rewards** | Supports three-tier referral rewards | Not supported |
| **Interface** | Beautiful custom page | No frontend display |
| **Authorization** | Requires wallet approval | No approval needed |

## 2. Creation Process

### Step 1: Go to the IDO Creation Page

Visit the CCBus IDO creation page and connect your wallet: [https://www.ccbus.cc/#/presale/createIDO](https://www.ccbus.cc/#/presale/createIDO)

### Step 2: Configure IDO Parameters

| Parameter | Description |
|-----------|-------------|
| **IDO Name** | Project name |
| **Token Address** | Your token contract address |
| **Payment Method** | BNB or USDT |
| **Start/End Time** | Start and end time of the IDO |
| **Token Price** | Presale price |
| **Purchase Limits** | Minimum/maximum purchase amount per address |
| **Distribution Mode** | Immediate distribution or unified distribution after the IDO ends |
| **Referral Rewards** | Up to three tiers of referral reward percentages can be set |

::: warning Important
The referring user must participate in the IDO first to activate the referral function. Invitation links from addresses that have not participated are invalid.
:::

### Step 3: Confirm Creation

After confirming all information, a wallet pop-up will appear for confirmation. Pay the fee to create the IDO.

### Step 4: Deposit Tokens

After successful creation, enter the console and click the "Deposit Tokens" button under "Global Control" to transfer the presale tokens into the contract.

### Step 5: Manage IDO Information

The console provides three management panels:

**Global Control**
- Deposit tokens
- Update receiving wallet address
- Withdraw remaining tokens

**Parameter Control**
- Adjust start/end time
- Modify purchase limits
- Change referral reward percentages
- Update token price

**Page Information Control**
- Custom logo
- Background image settings
- Global information (homepage text, whitepaper link, footer content, language settings)
- Project introduction and features
- Roadmap
- Social media links (X, Telegram, Discord, Github)

## 3. Fee Structure

| Fee Type | Amount |
|----------|--------|
| **Creation Fee** | 0.1 BNB (one-time) |
| **Transaction Commission** | 2% of each purchase |

Funds go directly to the project wallet after deducting referral rewards and platform fees.

## 4. FAQ

**Can the domain be changed?**

Yes, but you need to contact customer support for a paid modification.

**Can the tokenomics be modified?**

Tokenomics are auto-generated and cannot be modified at this time.

**Is multi-language supported?**

Currently only single-language display is supported — either Chinese or English. For bilingual display, please contact customer support.
