# Unlock Pool or Token Tutorial

## 1. Concept Overview

### What Is Unlocking?

Unlocking refers to withdrawing tokens that are locked in a smart contract, allowing them to re-enter market circulation. This operation can only be performed after the lock period has expired — it cannot be done before expiration.

### What Is Permanent Lock?

Permanent lock means placing tokens permanently in a smart contract where no one can withdraw them. This is an irreversible operation — the tokens can never be unlocked.

:::

## 3. FAQ

**Can locks created on other platforms be unlocked here?**

It depends on the source of the lock. Locks created on Pinksale can be viewed and unlocked through CCBus; locks from other platforms cannot.

**Is there a fee for unlocking or renouncing?**

These tools are currently free; service fees are only charged when initially creating a lock.
