# 靓号地址生成器

CCBus 靓号地址生成器可以为你生成带自定义前缀或后缀的个性化钱包地址。私钥完全在本地浏览器中生成，绝不上传到任何服务器。

工具地址：<https://ccbus.cc/toolset/vanity-address>

## 什么是靓号地址

靓号钱包地址是指包含特定字符或规律的钱包地址，一般出现在钱包的开头或者结尾（如以特定字母开头，或包含连续的 666、888 等）。它本质上与普通地址同样安全，但外观更具个性化和识别性。

靓号地址的生成原理是通过专用生成器，循环创建大量随机私钥，逐一筛选匹配满足特定规则（如指定前缀或后缀）的地址，此过程不修改区块链底层数据，只利用概率优势找到稀有地址。

## 靓号地址的用途

* **专属身份标识** — 方便 KOL 的粉丝以及合作伙伴快速、准确地找到收款地址，增强社交传播效果
* **打造独一无二的链上身份** — 用你的生日、名字缩写作为地址的一部分，在加密世界显得更专业、更有个性
* **降低转账出错** — 一个特定的、易记的后缀（如 `…8888` 结尾），相比完全随机的地址，能降低看花眼复制错的可能性

## 支持的链

* **EVM 链**：如 BSC、ETH、Base、Arbitrum 等 — 共用同一套地址格式，一把私钥可在所有 EVM 链使用
* **TRON（波场）链**：TRC-20 地址

> ⚠️ **我们不会存储私钥**，请您自行保管，丢失后无法找回！

## 操作流程

### 第 1 步：打开工具

进入 CCBus 首页，点击 **Toolset**（工具集），选择 **Vanity Address Generator**（靓号地址生成器）。

![Toolset 首页](/images/vanity/vanity-02-toolset-home.png)

打开后默认是 ETH 链界面：

![靓号地址生成器空状态](/images/vanity/vanity-16-empty-cn.png)

### 第 2 步：选择链

* **ETH**：可以生成 EVM 链钱包（包括 BSC、Base、Arbitrum 等）
* **TRON**：生成波场 TRC-20 钱包

切换链时，已输入的前缀/后缀中不兼容的字符会被自动过滤。

### 第 3 步：输入前缀和后缀

* **前缀**：地址开头需要的字符（`0x` 或 `T` 之后）
* **后缀**：地址结尾需要的字符
* 总长度建议 **≤ 5 位**，避免搜索时间过长
* ETH 链字符集：`0-9`、`a-f`；TRON 链字符集：Base58（不含 `0`、`O`、`I`、`l`）

可以点击下方的"幸运图案"按钮快速填入常用前缀：

![幸运图案按钮](/images/vanity/vanity-07-lucky-pattern-en.png)

输入后，预览区会实时显示目标地址形状，例如 `0x…8888…dead`：

![前缀和后缀都已填写](/images/vanity/vanity-17b-prefix-suffix-filled-cn.png)

下方的"温馨提示"会显示当前字符集和长度建议：

* **ETH**：`前缀和后缀只能包含 0-9、a-f 字符。建议总长度不超过 5 位，避免耗时过久。`
* **TRON**：`TRON 地址总是以 T 开头，所以前缀从第 2 位开始匹配。仅使用 Base58 字符（不含 0、O、I、l）。建议总长度不超过 5 位。`

### 第 4 步：调整高级设置

**区分大小写**（仅 ETH 链）：开启后必须匹配 EIP-55 校验和的大小写，难度大幅增加。

**线程数**：决定同时计算多少个候选地址，也意味着占用你电脑的多少 CPU 资源。线程数越大，占据的电脑资源越多（你的电脑在干其他事情的时候会越卡）。本机默认根据 CPU 核心数自动设置。

![区分大小写 + 高级设置](/images/vanity/vanity-08-case-sensitive-en.png)

**找到后继续挖掘**：开启后，挖掘器在找到第一个匹配后不会停止，会继续收集更多匹配地址，适合批量生成。

### 第 5 步：开始挖掘

点击 **开始** 按钮，右侧摘要面板会实时显示：

* **选择链** — 当前选择的链
* **难度** — 平均需要尝试的私钥数量
* **稀有度** — 五档等级（普通 / 罕见 / 稀有 / 史诗 / 传奇）
* **预计时间 (50%)** — 以当前速度估算找到匹配的时间
* **已生成** — 已收集到的匹配地址数量

![生成摘要面板详情](/images/vanity/vanity-18c-summary-detail-cn.png)

### 第 6 步：查看并备份结果

找到匹配后，页面底部会出现结果卡片：

* 绿色对勾图标
* 链名和搜索耗时
* **钱包地址**（前缀和后缀高亮显示）
* **私钥**（默认隐藏 — 点击 **显示** 按钮后才会展示）
* 显眼的"立即备份私钥"警告

**这是最关键的一步。** 点击 **显示** 按钮查看私钥后：

1. 立即复制私钥
2. 粘贴到密码管理器中、手写在纸上，或导入硬件钱包
3. **切勿** 把私钥告诉任何人

![找到结果并显示私钥](/images/vanity/vanity-19-result-cn.png)

> ⚠️ **危险警告**：丢失的私钥**无法找回**。没有"忘记密码"流程。CCBus 服务器不存储私钥 — 离开此页面后，浏览器中的私钥也会消失。

### 关于助记词 / 私钥助记词（恢复短语）

你可能已经注意到，本工具只给你 **地址和私钥** — **没有 12 个或 24 个单词的助记词（恢复短语 / 助记词）**。这是**设计如此**，不是 bug。

助记词是 HD（分层确定性）钱包的**根**：它编码了一段熵，钱包中所有的私钥都从这个根按 `m/44'/60'/0'/0/0` 这类派生路径确定性推导而来。而 CCBus 工具直接用 `crypto.getRandomValues()` 生成一个 32 字节的原始私钥**当作私钥使用** — 没有种子、没有派生路径、没有 HD 树。靓号地址的挖掘过程是：不断生成随机私钥，直到某个私钥对应的公钥哈希恰好匹配你设定的模式。过程中根本没有助记词可言 — 没有"根"可以"短句化"。

> **重要提示 — 把私钥导入 MetaMask 之前请先读完：**
> - 用私钥导入 MetaMask（账户菜单 → 导入账户 → 私钥）时，MetaMask 会创建一个 **"已导入"（Imported）账户**，并且**不会为它显示助记词**。没有助记词可显示 — 这个账户只作为那一个私钥存在。
> - 如果你重置 MetaMask、用其他助记词恢复、或者换到新设备，**这个已导入账户会消失**，除非你再次导入私钥。
> - **不能**从这个私钥反推出助记词。两者关系是单向的：助记词 → 多个私钥，而不是私钥 → 助记词。
>
> 简而言之：**私钥本身就是唯一的备份**。请按这个级别来对待它。不要指望 MetaMask 标准的"助记词备份"能覆盖这个账户。

如果你既想要靓号地址，又想要可恢复的助记词，有两个实用方案：

1. **把靓号地址当作一次性热钱包。** 挖出来、导入、用它收款，然后**把余额**扫到（转账到）一个你有助记词的正常钱包（例如新创建的 MetaMask / 硬件钱包）。靓号账户只负责"收款"；助记词账户负责"长期保存"。
2. **使用能从已知助记词派生出靓号地址的工具。** 一些高级工具允许你提供自己的熵 / 助记词，然后不断遍历派生路径，直到某个派生地址匹配你的模式。这种方法**指数级**更慢（通常在高性能机器上也要几分钟到几小时才能挖出 2 字符前缀），也不是 CCBus 这个工具的做法。

### 批量生成与导出

开启 **找到后继续挖掘** 后，所有匹配项会加入结果表格。表格标题显示匹配总数，例如 **全部结果 (8)**。可以点击 **CSV** 按钮下载所有匹配项的地址和私钥（CSV 格式），或点击 **清空** 清空内存中的结果。

CSV 文件格式：

```csv
address,private_key
0x8888abc...def,0x...
0x8888123...456,0x...
```

> ⚠️ CSV 文件包含**明文私钥**，请妥善保管并在导入钱包后安全删除。

![全部结果表格与 CSV 导出](/images/vanity/vanity-20-all-matches-cn.png)

## 难度与稀有度

| 稀有度 | 难度范围 | 说明 |
|--------|---------|------|
| 普通 | ≤ 16 | 1 个十六进制字符 — 瞬间完成 |
| 罕见 | ≤ 4,096 | 2 个十六进制字符 — 不到 1 秒 |
| 稀有 | ≤ 1,048,576 | 3–4 个十六进制字符 — 几秒到 1 分钟 |
| 史诗 | ≤ 1,000,000,000 | 5–6 个十六进制字符 — 几分钟到几小时 |
| 传奇 | > 10 亿 | 7+ 字符 — 单机可能需要数天 |

建议前缀 + 后缀总长 **≤ 5** 以获得舒适的挖掘体验。

## 常见问题

**1、生成靓号地址要钱吗？**
完全免费。该工具在你的浏览器中运行，不需要连接钱包或付费。

**2、靓号钱包私钥会泄露吗？**
不会。所有钱包都在你本地生成，CCBus 拿不到你的私钥。重要的是你自己要妥善保管私钥，并确保操作时周围没有其他人或摄像头。

**3、可以生成 BSC 靓号钱包吗？**
完全可以，BSC 和 ETH 用的是同一套钱包地址/私钥，选择 ETH 生成的钱包，就是 BSC 钱包了。

**4、为什么不可以生成 Solana 靓号钱包地址？**
Solana 靓号钱包地址使用 Ed25519 加密，请前往其他专用工具。

**5、为什么我的靓号地址半天生成不出来？**
如果您设置的靓号数字较多、前后缀越长，或者较为复杂，则生成难度会很大，这样生成的就非常慢。此外，电脑越好、配置越高，生成的速度会更快。

**6、可以同时指定前缀和后缀吗？**
可以。难度为两者的乘积，例如 ETH 链 3 位前缀 + 3 位后缀平均需要 16⁶ ≈ 1670 万次尝试。

**7、怎么把生成的地址导入 MetaMask？**
点击 **显示** → 复制私钥。打开 MetaMask：账户菜单 → 导入账户 → 粘贴私钥即可。

**8、我把私钥弄丢了，能找回来吗？**
不能。CCBus 不存储你的私钥，它仅在挖掘会话期间在浏览器中显示。如果没复制就关闭或刷新了页面，私钥就永远丢失了。

**9、这个账户有助记词（恢复短语）吗？**
没有。工具只生成一个原始私钥 — 没有助记词，也没有 HD 派生。导入 MetaMask 后是"已导入"账户，MetaMask 不会为它显示助记词。私钥本身就是你唯一的备份。详见上面的 [关于助记词 / 私钥助记词（恢复短语）](#关于助记词--私钥助记词恢复短语) 一节。
