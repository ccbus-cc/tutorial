# 分红本币

## 1、功能解释

分红本币，指的是持币分本币（所谓本币，就是**你发行的代币**）。用户从每一笔交易中，按照分红税率扣除一定的代币给到所有持币人。每个持币人所能分到的奖励，和它所拥有的代币数额有关系。持仓越大，分到的奖励越多。

::: warning 注意
该代币合约机制在发币完成后，**默认丢弃权限，不可进行任何修改**，也没有白名单、黑名单、杀机器人、交易开关等功能，是一个相对干净的合约。
:::

注：请提前下载好小狐狸钱包插件或欧易Web3钱包插件，小狐狸 MetaMask 安装教程：[小狐狸插件安装教程](/zh/practical-information/metamask)

## 2、连接钱包

首先，在小狐狸钱包里选择自己要发行代币的链，并切换到所在链。例如要在币安链发行代币，就切换到币安链。如果要在 Base 发币，就切换到 Base 链。

链切换好之后，打开发币页面：[https://www.ccbus.cc/#/create-token/holders-dividend](https://www.ccbus.cc/#/create-token/holders-dividend)，点击右上角连接钱包。

连接成功后，在发币页面的右上角会看到你的`链名称`和`钱包地址`。

## 3、参数说明

成功连接钱包后，在发币页面填写相应的参数：

<img src="/images/ccbus-holders-dividend-create.png" alt="分红本币创建表单" />

### 基础信息

| 参数 | 说明 |
|------|------|
| **代币全称** | 代币的名称信息，如 Ethereum。支持中文、英文以及中英混合文字 |
| **代币符号** | 代币简称，如 ETH。通常就是`看K软件`、`薄饼`、`钱包`中显示的名称。支持中文、英文以及中英混合文字 |
| **发行量** | 代币发行的总供应量，无法增发，固定发行。如果总量过多需要降低精度 |
| **精度** | 代表币的小数位数，如 0.000001 代表精度为 6。一般默认是 18 |
| **收币地址** | 创建代币后接收代币的钱包地址。默认为当前连接的钱包地址，也可以填写其他地址。该地址默认会被加入白名单 |

### 买入税率

不需要的部分填 0，**总比例小于 25%**

| 税率 | 说明 |
|------|------|
| **营销税率** | 每笔买入都会扣除对应比例本币发送到你的`营销钱包`地址 |
| **分红税率** | 每笔买入都会扣除对应比例的本币分给所有`持币地址` |
| **销毁税率** | 每笔买入都会扣除对应比例代币送进`黑洞地址`，达到销毁的目的 |
| **回流税率** | 每笔买入都会扣除对应比例代币送进`资金池` |

### 卖出税率

不需要的部分填 0，**总比例小于 25%**

| 税率 | 说明 |
|------|------|
| **营销税率** | 每笔卖出都会扣除对应比例本币发送到你的`营销钱包`地址 |
| **分红税率** | 每笔卖出都会扣除对应比例的本币分给所有`持币地址` |
| **销毁税率** | 每笔卖出都会扣除对应比例代币送进`黑洞地址`，达到销毁的目的 |
| **回流税率** | 每笔卖出都会扣除对应比例代币送进`资金池` |

### 其他必填项

| 参数 | 说明 |
|------|------|
| **营销钱包** | 用来接收营销税率的钱包，接收的是本币 |
| **选择交易所** | 不同的链会有不同的交易平台（如 ETH 链有 Uniswap，BSC 链有 PancakeSwap 等）。选择什么交易所，就去那里添加流动性。搞错了会导致机制无法执行，请注意 |
| **选择底池代币** | 支持选择 `BNB`、`USDT` 等池子。选择哪种底池代币，就必须做哪种池子，才能保证交易机制的顺利进行 |

## 4、创建合约

确认填写的参数无误后，点击**"创建合约"**按钮。

小狐狸钱包会弹出确认窗口，要求你支付 Gas 费，点击确认。等待几十秒，合约就创建完成了。

::: tip 提示
- 创建成功后会自动跳转到控制台设置页面
- 代币已经发送到你填写的收币地址里
- 合约默认已开源，无需手动开源
- 合约创建后默认丢弃权限，无法再进行任何修改
:::

## 5、添加流动性

代币创建完成之后，只能转账，还不能交易。需要前往你选择的交易所创建流动性资金池：

1. 打开对应 DEX（PancakeSwap / Uniswap 等）
2. 找到"交易 - 流动性"，选择 **V2 版本**
3. 选择你的代币 + 底池代币（BNB / USDT 等），填写初始数量
4. 依次点击`批准代币` → `添加`

::: warning 重要
第一次添加流动性必须做 **V2** 的池子，不能做 V3 的池子。V3 不支持任何税率机制，只能在 V2 做，请注意。
:::

## 注意事项

| 问题 | 说明 |
|------|------|
| **黑洞地址会不会参与分红？** | 黑洞地址如果持有代币，同样会参与分红 |
| **权限与修改问题** | 合约创建完成后默认丢弃权限，无法再通过控制台对合约进行任何形式的修改 |
| **V2 和 V3 流动性** | 第一次添加流动性必须做 V2 的池子，V3 不支持任何机制 |
