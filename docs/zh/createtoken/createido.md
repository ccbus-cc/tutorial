# IDO预售公募创建教程

## 一、什么是IDO？

IDO（Initial DEX Offering）即"首次去中心化交易所发行"，是在去中心化交易所上进行代币发行的一种方式。项目方在上线前以较低价格出售代币，用于筹集资金用于流动性池和营销。

### IDO与Mint的区别

| 特性 | IDO | Mint |
|------|-----|------|
| **参与方式** | 通过官网参与 | 通过钱包转账 |
| **推荐奖励** | 支持三级推荐奖励 | 不支持 |
| **界面** | 精美的自定义页面 | 无前端展示 |
| **授权** | 需要钱包授权 | 无需授权 |

## 二、创建流程

### 步骤1：进入IDO创建页面

访问CCBus的IDO创建页面，连接钱包：[https://www.ccbus.cc/#/presale/createIDO](https://www.ccbus.cc/#/presale/createIDO)

### 步骤2：配置IDO参数

| 参数 | 说明 |
|------|------|
| **IDO名称** | 项目名称 |
| **代币地址** | 你的代币合约地址 |
| **支付方式** | BNB或USDT |
| **开始/结束时间** | IDO的起止时间 |
| **代币价格** | 预售价格 |
| **购买限制** | 单个地址的最低/最高购买额度 |
| **发放模式** | 立即发放或结束后统一发放 |
| **推荐奖励** | 可设置最多三级推荐比例 |

::: warning 重要提示
上级用户必须自己先参与IDO，才能激活推荐功能。未参与的地址，其邀请链接无效。
:::

### 步骤3：确认创建

确认所有信息后，钱包弹出确认窗口，支付费用即可创建。

### 步骤4：充值代币

创建成功后进入控制台，在"全局控制"中点击充值代币按钮，将预售所需的代币转入合约。

### 步骤5：管理IDO信息

控制台提供三个管理面板：

**全局控制**
- 充值代币
- 更新收款钱包地址
- 提取剩余代币

**参数控制**
- 调整开始/结束时间
- 修改购买额度限制
- 更改推荐奖励比例
- 更新代币价格

**页面信息控制**
- Logo自定义
- 背景图片设置
- 全局信息（首页文字、白皮书链接、页脚内容、语言设置）
- 项目介绍和特性
- 路线图
- 社交媒体链接（X、Telegram、Discord、Github）

## 三、收费标准

| 费用类型 | 金额 |
|----------|------|
| **创建费用** | 0.1 BNB（一次性） |
| **交易抽成** | 每笔购买的2% |

资金在扣除推荐奖励和平台费用后，直接进入项目方钱包。

## 四、疑问解答

**可以修改域名吗？**

可以，需要联系客服进行付费处理。

**代币经济学可以修改吗？**

目前自动生成，暂不支持修改。

**支持多语言吗？**

目前仅支持单语言显示，中文或英文选其一。如需双语同时显示，请联系客服。

如有不明白或者不清楚的地方，请加入官方电报群：[@CCBus](https://t.me/CCBus)
