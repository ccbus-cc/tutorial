# 代币批量交易/市值管理教程

## 一、市值管理工具概述

CCBus为EVM兼容链开发的升级版市值管理工具，支持更多区块链网络、更快的速度和多样化的流动性池兼容性。

### 核心功能

用户可以导入多个钱包地址，针对特定代币进行批量交易，通过配置交易频率和价格参数来自动化大规模交易操作。

### 支持的网络和池子类型

| 区块链 | 支持的交易所 |
|--------|-------------|
| **BNB Chain** | PancakeSwap V2, V3 |
| **Ethereum** | Uniswap V2, V3 |
| **Avalanche** | Uniswap V2, V3 |
| **Polygon** | Uniswap V2, V3 |
| **Arbitrum** | Uniswap V2, V3 |
| **Optimism** | Uniswap V2, V3 |
| **Base** | Uniswap V2, V3 |

## 二、操作说明

### 1、查询流动性池

配置基本参数：

| 参数 | 说明 |
|------|------|
| **选择链** | 选择目标代币所在的区块链 |
| **交易所类型** | 选择V2或V3池子 |
| **报价代币** | 确认你池子的底池币种（BNB、ETH、USDT） |
| **代币地址** | 输入目标代币的合约地址 |

查询成功后，界面会显示代币价格和池子确认信息。

### 2、导入钱包

点击导入按钮，输入钱包私钥（每行一个）。通常需要导入几十个钱包才能有效运作。

导入后刷新余额，确认所有导入地址的代币持有情况。

### 3、买入/卖出交易设置

**数量配置方式：**
- **按数量**：固定交易金额
- **按百分比**：钱包余额百分比。例如设置1%，钱包有1000 USDT，则第一笔交易执行10 USDT

**停止条件：**

| 参数 | 说明 |
|------|------|
| **价格停止** | 达到指定价格后停止 |
| **交易次数** | 达到指定次数后停止 |
| **间隔时间** | 每笔交易之间的间隔（秒） |
| **线程数** | 每秒最多同时执行的交易数（最大6笔） |

### 4、买卖交易（自动模式）

与单方向交易不同，买卖交易会自动执行买入和卖出操作。

| 参数 | 说明 |
|------|------|
| **买入/卖出金额范围** | 设置交易金额区间 |
| **买卖概率比** | 买入和卖出的概率比例（总和为100%） |
| **交易次数** | 停止条件 |
| **间隔和线程** | 同上 |

## 三、疑问解答

**代币地址正确但报错？**

确认区块链和交易所池子类型选择是否正确。

**交易失败？**

通常是Gas不足或代币余额不足导致。

**私钥安全吗？**

私钥仅存储在你本地电脑页面中，不会上传到服务器。

**钱包数量有限制吗？**

理论上无限制，但一般几十个是最佳平衡点，兼顾用户体验和CPU性能。

**收费标准？**

请查看工具页面右上角的当前收费标准。
