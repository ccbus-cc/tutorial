# 加池开盘并捆绑买入教程

## 一、什么是捆绑买入？

在代币上线创建第一个流动性资金池时，多个地址可以同时以最低价格购买代币。这种同步操作将加池子和立即买入代币结合在一起。

### 为什么使用捆绑买入？

- **最低价获取**：项目方以比手动购买更快的速度、更高的成功率获取代币
- **公平分配**：通过购买而非预留代币来建立用户信任
- **防机器人**：在加池子的瞬间买入，比自动机器人更快、价格更优

## 二、重要注意事项

### 1、将路由合约加入白名单

如果你的代币有特殊功能（如手动开盘、持币限制等），需要先将CCBus的路由合约加入白名单：

::: tip 路由合约地址
**CCBus Router:** `0x60c8E6DAAfD4D24fEa43E01CE1EC1ecDa3eE1143`
:::

### 2、将捆绑地址加入白名单

如果你的代币有交易限制或防机器人措施，需要预先将所有捆绑买入地址加入白名单。

### 3、确保BNB余额充足

加池地址必须持有足够的BNB，既要覆盖加池费用，也要覆盖捆绑买入的Gas费。

### 4、私钥安全提醒

::: warning 安全警告
捆绑买入需要导入私钥。虽然CCBus不会存储私钥，但请务必注意电脑安全，防止恶意软件和剪贴板泄露。
:::

## 四、疑问解答

**标准代币为什么失败？**

确保钱包余额充足：捆绑钱包最少需要0.01 BNB；加池钱包每个地址需要0.02 BNB。

**功能代币为什么失败？**

检查路由地址和捆绑地址是否加入白名单，确认交易未被手动锁定，确认持币限制未生效。

**捆绑地址会被杀机器人吗？**

如果代币有防机器人功能，会的。请提前将捆绑地址加入白名单。

**底池是BNB，可以用USDT买吗？**

可以，配对资产可以互换交易。

**加池数量有要求吗？**

没有严格要求，根据你的代币经济学设置。一般建议池子大于300 USDT或1 BNB。

**V2和V3的区别？**

功能代币只能使用V2；V3目前只支持标准币，主要用于稳定池。
