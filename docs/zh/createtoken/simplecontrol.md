# 多功能代币创建教程

## 1、功能解释

多功能代币是具有多种能力的智能合约集合，包括代币增发、交易暂停、黑名单功能和最大持币限制。用户在部署后可获得丰富的操作选项。

::: warning 安全检测提示
创建后，部分安全检测平台可能会"显示风险"。标准代币可以消除这些问题。创建此类型代币即表示接受检测风险。创建后，某些检测平台允许在丢弃权限后重新审计以消除标记的风险。
:::

## 2、连接钱包（老手忽略该操作）

首先，在小狐狸钱包里选择自己要发行代币的链，并切换到所在链。例如我要在币安链发行代币，就切换到币安链上。

如果要在Base发币，就切换到Base链。要在以太坊发币，就切换到ETH链，这里就不演示了。

链切换好之后，打开发币页面：[https://www.ccbus.cc/#/coinrelease/simpleControl](https://www.ccbus.cc/#/coinrelease/simpleControl)，点击右上角连接钱包。

之后会弹出小狐狸让你确认要连接的钱包地址。点击下一步并确认之后，就会连接成功了。在发币页面的右上角，会看到你的`链名称`和`钱包地址`，这就算完成了。

## 3、参数说明

成功连接钱包后，我们在发币页面填写相应的参数：[https://www.ccbus.cc/#/coinrelease/simpleControl](https://www.ccbus.cc/#/coinrelease/simpleControl)

| 参数 | 说明 |
|------|------|
| **代币全称** | 代币的名称信息，支持中文、英文以及中英混合文字 |
| **代币符号** | 也就是代币简称，如ETH |
| **发行量** | 代币发行的总供应量，如未开启增发功能则无法增发，固定发行 |
| **精度** | 代表币的小数位数，如：0.000001代表精度为6，一般默认是18 |
| **收币地址** | 创建代币后接收代币的钱包地址。默认为当前连接的钱包地址，也可以填写其他地址 |

## 4、功能开关

| 功能 | 说明 |
|------|------|
| **增发代币** | 启用后可以在控制台增发代币；一旦关闭则无法再开启 |
| **交易暂停** | 启用后可以暂停所有代币的转账和交易，可手动开关 |
| **黑名单功能** | 可以添加/移除地址；被加入黑名单的钱包无法卖出或转账 |
| **最大持币量** | 设置每个钱包的最大持币限制；如果上线时未启用，后期无法再开启 |

## 5、控制台说明

当我们成功发行代币后，可进入控制台：[https://www.ccbus.cc/#/coinrelease/console](https://www.ccbus.cc/#/coinrelease/console)，对代币的各项功能进行管理：

### 权限控制

| 操作 | 说明 |
|------|------|
| **转让所有权** | 将合约权限转让给其他人（转移权限之前，记得复制`控制台链接`） |
| **放弃所有权** | 将合约权限丢至黑洞，永远不能拿回（不可逆操作，会导致所有功能失效） |

### 交易控制

| 操作 | 说明 |
|------|------|
| **暂停/恢复交易** | 暂停所有非白名单地址的转账交易 |
| **修改持币上限** | 调高或者降低每个地址持币的限制 |
| **关闭持币限制** | 关闭后每个地址的持币数量不再受限 |
| **管理黑名单** | 添加/移除黑名单地址 |
| **设置白名单** | 白名单地址不受任何限制 |

### 代币管理

| 操作 | 说明 |
|------|------|
| **增发代币** | 手动执行代币增发 |
| **提取合约代币** | 提取合约地址内的BNB和代币 |

## 6、疑问解答

**为什么加池子失败？**

如果钱包持币限制是100个，但加池子需要101个，就会失败。可以先加99个的池子，然后将池子地址加入持币白名单。

**为什么白名单用户在暂停期间也不能买？**

因为池子地址在暂停期间也无法转账。将池子地址加入白名单即可恢复交易。

**为什么正常交易时卖出失败？**

池子持币量达到了限制。需要提高持币上限或将池子地址加入持币白名单。
