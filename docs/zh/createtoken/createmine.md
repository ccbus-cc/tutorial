# 质押挖矿创建教程

## 一、质押挖矿概念

### 什么是质押挖矿？

将某种代币或LP通过官网质押到合约里暂时无法取出，从而获得另一代币奖励的机制，就是质押挖矿。

- **质押**：将代币存入挖矿合约，在锁定期结束前无法取出
- **挖矿**：通过质押参与获得奖励

### 为什么要创建质押挖矿？

代币创建后，用户可以自由买卖和加撤池子。但卖出和撤池子会损害项目稳定性。质押挖矿通过暂时锁定用户仓位和LP来降低代币崩盘风险。

- **代币挖矿**：减少流通量，阻止用户购买后立即抛售
- **LP挖矿**：降低撤池风险，防止投资者退出池子

## 二、如何创建质押挖矿

::: warning 前提条件
创建前请确保你已经创建了代币并拥有合约地址，否则无法创建挖矿。
:::

### 1、进入创建页面

访问：[https://www.ccbus.cc/#/mine/createMine](https://www.ccbus.cc/#/mine/createMine)，右上角连接钱包。

### 2、配置挖矿信息

| 参数 | 说明 |
|------|------|
| **挖矿名称** | 任意名称，支持中文、英文或混合文字 |
| **质押代币** | 输入代币合约地址；用户将此代币存入池子。如果是LP挖矿，输入LP合约地址 |
| **奖励代币** | 输入奖励代币合约地址（通常为USDT/USDC，也可以是任意代币） |
| **查询代币** | 输入地址后点击查询按钮，验证代币是否有效 |
| **开始时间** | 指定挖矿开始的确切时间（时区为你设备的当前时区） |
| **挖矿时长** | 设置质押周期（可自定义天数） |
| **每日奖励数量** | 每日产出量（后期可修改；注意奖励是**按秒**产生的） |
| **锁定时间** | 质押后是否需要锁定；输入0表示不锁定，或输入锁定天数（24小时=1天） |
| **质押数量限制** | 设置最低和最高质押数量（后期可修改） |
| **推荐奖励** | 最多三级推荐；分别设置每级奖励比例 |
| **语言设置** | 选择中文或英文（仅支持单语言） |

::: warning 推荐奖励注意
只有先参与挖矿，才有资格推荐别人，否则邀请链接是没有用处的。
:::

### 3、创建挖矿

确认所有信息后，点击创建按钮。钱包弹出确认窗口，确认并支付费用即可。

等待几秒钟确认后，点击进入控制台。

### 4、充值奖励代币

挖矿合约已创建但尚无奖励代币，无法分发奖励。进入控制台右侧"全局控制"，点击充值代币按钮。

输入奖励代币数量，钱包确认后完成充值。如果后期奖励不足，可以继续充值。挖矿结束后，也可以通过提取功能取回剩余代币。

充值完成后，挖矿条件已满足。控制台提供质押挖矿页面入口，用户可以连接钱包、输入质押数量并参与。

质押成功后，奖励每秒累积。点击领取按钮即可提取。注意：用户在锁定期结束前无法取回质押的代币。

### 5、修改挖矿参数

控制台的挖矿参数控制区域支持修改：

| 操作 | 说明 |
|------|------|
| **修改时间** | 调整挖矿周期（30天、100天、300天等） |
| **修改质押限制** | 更改最低/最高质押数量 |
| **修改推荐奖励** | 调整各级推荐奖励比例 |
| **修改每日奖励** | 更改每日奖励代币产出量 |
| **修改锁定时间** | 调整用户质押后的锁定时长 |

### 6、修改官网信息

控制台右下方"页面信息控制"支持修改官网内容和图片：

- **修改Logo**：上传图片或输入图片URL
- **修改背景图片**：建议使用深色背景
- **修改全局信息**：首页简介、白皮书链接、页脚内容、网站语言
- **修改介绍**：项目介绍标题和详细描述
- **修改特性**：四个主要特点，各含标题和描述
- **修改路线图**：四个发展阶段
- **修改社交链接**：X（推特）、Telegram、Discord、Github

## 三、疑问解答

**为什么推荐奖励不生效？**

只有参与质押的地址才有资格推荐；未参与的地址无法使用推荐链接。

**多次质押的解锁时间怎么算？**

以最后一次质押时间为准；解锁时间=最后质押时间+锁定期。

**质押奖励怎么发放？自动发放吗？**

奖励每秒累积在账户里，质押用户需要手动点击领取，才能将奖励拿到自己钱包。领取没有次数限制，随时可以领取。但每次只能全部领取，不支持部分提取。

**用户可以提前解除质押吗？**

用户没有提前退出的机制，除非项目方将锁定时间修改为零。

**可以质押LP参与挖矿吗？**

可以。创建挖矿时在质押代币字段输入LP合约地址即可。

**挖矿官网域名可以修改吗？**

可以，需要联系客服进行付费处理。
