# 创建流动性资金池教程

## 一、什么是流动性资金池？

流动性资金池（LP，也叫"底池"或"池子"）是"一个基于区块链的代币储备库，使交易所能够进行代币交换，通常由两种代币按特定比例组成"。

**用途：** 没有池子就无法交易；池子使代币能够实时兑换。

## 二、加池子注意事项

### 1、将路由合约加入白名单

如果你的代币带有特殊功能（如手动开盘、持币限制等），需要先将CCBus的路由合约加入白名单：

::: tip 路由合约地址
**CCBus Router:** `0x60c8E6DAAfD4D24fEa43E01CE1EC1ecDa3eE1143`
:::

### 2、确保钱包余额充足

钱包内需要保留足够的Gas费。BSC链加池至少需要0.032个BNB。

### 3、V2和V3的区别

| 版本 | 说明 |
|------|------|
| **V2** | 支持所有代币类型（标准币、分红/销毁代币、复杂功能代币） |
| **V3** | 仅支持标准代币；CCBus支持通过V3创建稳定池 |

::: warning 注意
带功能/机制的币，只能加V2。目前V3的池子只支持标准币（主要做稳定池），大家不要加错了。
:::

## 三、加池子流程

### 1、连接钱包

打开加池页面：[https://www.ccbus.cc/#/createliquidity](https://www.ccbus.cc/#/createliquidity)，点击右上角连接钱包。

连接成功后，右上角会显示你的钱包地址。根据需要切换区块链网络（BSC选币安智能链，ETH选以太坊）。

连接钱包后，选择池子类型和代币：

| **代币地址** | 你创建的代币合约地址 |

点击"查询代币"，正常会提示"代币正常，请填写加池数量"。

::: tip 价格计算

## 四、疑问解答

**为什么加池子失败？**

首先确认一下自己钱包内的BNB/ETH数量是否足够，BSC链加池至少需要0.03个BNB。如果余额充足，那么再看下有没有将路由地址加入白名单。

**底池是BNB，用户可以用USDT买吗？**

可以的，交易对是互通的，用户可以使用任意配对代币进行购买。

**加池数量有要求吗？**

没有要求。可以根据你的代币经济学和价格需求，添加适当比例的代币。一般来说，我们要求池子尽量大于300U或1个BNB。

**预估价格会变吗？**

预估价格只是你的代币初始价格，即上线价格。后续随着不断交易，价格会不断变化。

**V2和V3的区别？**

带功能/机制的币，只能加V2。目前V3的池子只支持标准币（主要做稳定池），大家不要加错了。
