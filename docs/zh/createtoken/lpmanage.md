# 增加/移除流动性资金池教程

已经在PancakeSwap或Uniswap创建了流动性资金池的用户，可以通过CCBus的"流动性控制台"查看和管理自己的池子。

主要支持两种操作：
- **增加流动性**：向池子注入更多代币，扩大资金池规模
- **移除流动性**：撤出池子资金，停止交易

## 一、连接钱包

打开流动性控制台：[https://www.ccbus.cc/#/LPmanage](https://www.ccbus.cc/#/LPmanage)，右上角连接钱包并选择对应的区块链。连接成功后，刷新页面即可自动查看你的流动性情况。

## 二、增加流动性

点击"增加流动性"按钮后：

| 步骤 | 说明 |
|------|------|
| **输入数量** | 填写两个代币（底池代币和你的代币）的加池数量 |
| **授权代币** | 分别授权两个代币，钱包确认 |
| **确认添加** | 确认数量和授权无误后，点击执行 |

添加成功后会有提示。

## 三、移除流动性

移除流动性即从池子中撤出代币，可以按比例撤出或全部撤出。

| 参数 | 说明 |
|------|------|
| **移除比例** | 选择0-100%的撤出比例 |
| **LP数量** | 自动计算；这些LP代币会被销毁 |
| **预估到账** | 预计返还的两种代币数量 |
| **接收钱包** | 默认为操作钱包，也可以填写其他地址 |
| **LP授权** | 移除前需要通过路由合约授权LP |

点击确认撤出，等待钱包确认和成功提示即可。

## 四、锁定流动性（锁池子）

锁定流动性可以防止撤池，保护投资者权益。

| 参数 | 说明 |
|------|------|
| **锁定比例** | 你的池子份额百分比（注意不是总流动性百分比） |
| **锁定数量** | 自动计算的LP数量 |
| **解锁日期** | 根据你的时区设置；到期前不可撤出（不可逆） |
| **锁定标题** | 可选的命名字段 |
| **LP授权** | 锁定前需要授权 |

## 五、疑问解答

**为什么增加/移除操作失败？**

原生代币不足（BSC链最少需要0.011个BNB），或者路由地址未加入白名单。

::: tip 路由合约地址
**CCBus Router:** `0x60c8E6DAAfD4D24fEa43E01CE1EC1ecDa3eE1143`
:::

**锁池后代币还能交易吗？**

可以。锁池只是锁定了LP凭证，防止撤池，不影响正常交易。

**锁定的LP可以提前解锁吗？**

不可以。必须严格遵守锁定期限。

**Ave会显示锁池信息吗？**

会的，Pinksale锁池指标会显示。

**操作需要手续费吗？**

是的，增加、移除或锁定每次操作需要0.01 BNB。
