# 解锁池子或代币教程

## 一、概念说明

### 什么是解锁？

解锁是指将锁定在智能合约中的代币提取出来，使其重新进入市场流通。此操作需要等到锁定期到期后才能执行，到期前无法操作。

### 什么是永久锁定？

永久锁定是指将代币永久放置在智能合约中，任何人都无法取出。这是不可逆的操作，代币将永远无法解锁。

## 二、操作流程

连接钱包后，进入CCBus锁定控制台。界面会显示所有锁定信息：左边显示池子锁定，右边显示代币锁定。

当锁定期到期后，选择解锁选项，在钱包中确认即可取回代币。

### 2、放弃操作（永久锁定）

::: warning 不可逆操作
放弃意味着永久锁定——你自愿放弃取回代币的权利，意味着你永远无法取回这些代币。此操作不可逆，确认后无法恢复。
:::

## 三、疑问解答

**在其他平台创建的锁定可以在这里解锁吗？**

这取决于锁定来源。在Pinksale创建的锁定可以通过CCBus查看和解锁；其他平台的锁定则不行。

**解锁或放弃需要手续费吗？**

这些工具目前免费；服务费仅在初始创建锁定时收取。
