# 创建锁池或锁仓教程

## 一、概念说明

**代币锁仓（锁币）：** 将代币锁定在智能合约中无法转出，从而减少市场流通量。

**池子锁定（锁池）：** 项目方锁定LP代币凭证，防止撤出流动性池，消除Rug Pull风险。

**LP代币说明：** 当你提供两种代币作为流动性时，会收到LP代币作为贡献凭证。没有LP代币就无法撤池子。

**池子权限：** 池子没有权限系统——所有流动性提供者按比例共同拥有池子。

## 二、代币锁仓流程

### 1、连接钱包

打开锁仓页面，右上角连接钱包。

::: warning 注意事项
- 确保只有一个钱包插件处于活动状态
- 确认钱包地址和网络选择正确
:::

### 2、填写锁定信息

| 参数 | 说明 |
|------|------|
| **代币地址** | 输入代币合约地址 |
| **锁定数量** | 输入要锁定的数量 |
| **解锁日期** | 选择解锁日期 |
| **锁定标题** | 创建描述性名称 |

::: tip 重要提示
输入池子地址（LP代币地址）就是锁池子；输入代币地址就是锁代币。
:::

### 3、授权代币

确认信息无误后，点击授权并在钱包中确认。

### 4、执行锁定

仔细核对日期和数量后，点击锁定按钮，在钱包弹窗中确认。处理需要几秒钟。

进入锁定控制台查看所有锁定记录，到期后可以在此管理解锁。用户也可以点击"放弃"将锁定转为永久状态。

## 三、锁定流动性池（锁池子）

### 方式一：通过锁仓页面

在代币地址字段输入池子地址（LP地址），其余步骤与代币锁仓完全相同。

::: tip 如何获取池子地址
在流动性控制台中可以查看你的池子地址。
:::

### 方式二：通过流动性控制台直接锁定

打开流动性控制台，找到你的池子，直接点击锁定按钮。

![流动性控制台锁定](/images/placeholder.png)

**锁定参数说明：**

| 参数 | 说明 |
|------|------|
| **锁定比例** | 你在池子中的份额比例 |
| **锁定数量** | 自动计算的LP数量 |
| **解锁日期** | 根据本地时区；到期前LP无法取出 |
| **锁定标题** | 可选命名 |
| **LP授权** | 锁定前需要授权 |

::: warning 注意
如果池子只有你一个人加过流动性，那比例就等于池子比例。如果有多个提供者，计算方式不同。
:::

LP授权后，确认锁定并等待完成。

## 四、疑问解答

**为什么锁定失败？**

确认代币没有持币限制。确保钱包内至少有0.01 BNB。

**锁定需要手续费吗？**

需要，BSC链每次锁仓/锁池操作需要0.01 BNB。

**可以提前解锁吗？**

不可以。智能合约在指定时间前无法解锁。

**解锁时间用的是什么时区？**

默认为你的本地时区，无需手动调整。
