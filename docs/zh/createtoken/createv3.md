# 创建稳定币流动池教程

## 一、什么是稳定币池？

稳定币池是一种特殊的流动性池，适用于在BSC、以太坊等链上创建稳定币时使用。

**什么是稳定币？** 代币交易价格相对稳定。原生稳定币如USDT、USDC锚定美元，而本教程讨论的稳定币锚定USDT/USDC。

**如何让币价稳定？** 通过创建流动性池，将代币与USDT兑换比例固定（如"1代币=1USDT"），无论交易量多少，比例保持一致。

## 二、如何创建稳定币池

### 步骤1：发行标准币

创建稳定池前需要先发行代币。要求：无交易税率、无持仓限制。

推荐类型：
- [标准代币创建](/zh/createtoken/stardand)
- [多功能代币创建](/zh/createtoken/simplecontrol)

### 步骤2：进入创建稳定池页面

访问：[https://www.ccbus.cc/#/createV3](https://www.ccbus.cc/#/createV3)

操作：

- 选择对应的区块链

### 步骤3：输入代币信息并查询

| 参数 | 说明 |
|------|------|
| **选择交易所** | BSC链默认选Pancake V3 |
| **选择底池代币** | 一般选USDT |
| **加池代币地址** | 输入发行代币的合约地址 |

点击"查询代币"，成功后会有提示。

### 步骤4：确认交易价格与加池数量

| 参数 | 说明 |
|------|------|
| **交易价格** | 代币稳定在的价位。一旦确定，买卖都按此价格执行 |
| **加池数量** | 往池子里投入的代币数量 |

::: tip 单币加池
稳定币流动池采用"单币加池模式"。仅需放入发行的代币，USDT/USDC等无需入池。
:::

### 步骤5：授权并创建

1. 点击"授权代币"，钱包弹出确认
2. 授权完成后，点击"立即加池"按钮
3. 进行二次确认
4. 钱包弹出最终确认，确认即可

## 三、疑问解答

**为什么查不到代币？**

确保代币合约地址、所选链无误。若无误，尝试切换网络后刷新重试。

**代币价格能确保稳定吗？**

是的。创建成功后，买卖价格固定不变。

**池子没有放U，怎么卖？**

单币池仅放入代币，无USDT无法卖出。需先通过他人买入向池子存入USDT，之后才能卖出。

**创建稳定池后能加其他池子吗？**

不行。稳定池目的是保持价格稳定，其他池子会改变价格。

**能在后期修改价格吗？**

无法修改。价格一旦创建即固定，不可调整。

**池子交易后，钱包能显示价格吗？**

不一定。各钱包对代币价格显示逻辑不同，需咨询钱包方。
